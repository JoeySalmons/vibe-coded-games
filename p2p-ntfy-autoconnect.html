P2P Chat

Auto-connects via ntfy.sh. No accounts, no server — just a shared passphrase on any network.

How it works: The passphrase derives a private ntfy topic name and an AES-256 encryption key. ntfy carries the encrypted WebRTC handshake; all chat traffic flows directly peer-to-peer and is never relayed. The topic resets each UTC day — start a new session with the same passphrase tomorrow and you'll get a fresh room.
